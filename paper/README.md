# Paper artifacts

Everything here exists to produce a figure or a table. The benchmark harness
itself lives in [bench/](../bench/); this directory consumes its output.

```text
microbench/   standalone gather/scatter microbenchmark, no repo dependency
analysis/     structural properties of the matrix set, .mtx -> csv
plots/        csv -> figures
data/         the numbers the paper cites, committed
figures/      the figures the paper includes, committed
```

`data/` and `figures/` are committed on purpose. `bench/results/` is
gitignored because it is machine-specific and regenerated by every sweep, so
without a copy here nothing in the paper would be reproducible from a clone.

## Regenerating

Structural properties come from the `.mtx` files alone and take seconds.

```bash
python3 paper/analysis/vector_fill.py
python3 paper/analysis/accumulator_ratio.py
```

The measured data comes from the board. After a sweep, copy the summary in:

```bash
cp bench/results/summary.csv paper/data/
```

The microbenchmark is built and run separately, on the board.

```bash
$CC -O3 -march=rv64gcv -mabi=lp64d -fno-tree-vectorize -fno-tree-slp-vectorize \
    -DPERF paper/microbench/gather_scatter.c -o paper/microbench/gather_scatter -lm
taskset -c 0 ./paper/microbench/gather_scatter > paper/data/gather_scatter.csv
```

Then the figures, which read `paper/data/` and write `paper/figures/`:

```bash
for f in paper/plots/*.py; do python3 "$f"; done
```

Each plot also accepts explicit paths, so an alternative dataset can be
plotted without moving files.

## Figures

| Figure | Script | Inputs |
| --- | --- | --- |
| `parity.pdf` | `plots/parity.py` | summary, vector_fill |
| `lmul.pdf` | `plots/lmul.py` | summary, vector_fill |
| `cost_vs_ratio.pdf` | `plots/cost_vs_ratio.py` | summary, accumulator_ratio |
| `stall_vs_ratio.pdf` | `plots/stall_vs_ratio.py` | summary, accumulator_ratio |
| `openmp.pdf` | `plots/openmp.py` | summary |
| `microbench.pdf` | `plots/microbench.py` | gather_scatter |

Plotting needs `pandas` and `matplotlib`; the analysis scripts need `scipy`.
The harness and the microbenchmark need neither.
